# 제설창고관리시스템 (Snow Storage Management System)

현장 창고 담당자와 사무실 담당자가 함께 사용하는 제설자재 재고/입출고 관리 웹앱(PWA)입니다.

## 구성

- **backend/**: Node.js + Express + SQLite(Node.js 내장 `node:sqlite` 모듈) API 서버 — 별도 컴파일 도구 없이 `npm install`만으로 설치됩니다
- **frontend/**: React + Vite 기반 PWA (설치형 웹앱, 오프라인 입력 지원)

> **Node.js 버전**: 22.5 이상 필요 (내장 SQLite 모듈 사용). `node -v`로 확인하세요. 최신 LTS 버전 설치를 권장합니다.

## 핵심 설계

- **입출고 원장 방식 재고 계산**: 재고 수량을 별도로 저장하지 않고, 모든 입출고 거래(`transactions`)의 합계로 현재 재고를 계산합니다. 여러 창고에서 오프라인으로 동시에 기록해도 서버에 반영될 때 값이 충돌하지 않습니다.
- **오프라인 입력**: 프론트엔드는 PWA로 설치 가능하며, 네트워크가 끊긴 상태에서 입출고를 등록하면 브라우저 IndexedDB에 임시 저장됩니다. 온라인 상태가 되면 자동으로 서버와 동기화됩니다(`client_id` 기반 중복 방지).
- **역할 기반 화면**: `admin`(관리자) / `office`(사무실) / `field`(현장) 세 가지 역할로 로그인하며, 현장 계정은 입출고 등록·재고 조회 화면 위주로, 사무실/관리자는 대시보드·이력·마스터 관리 화면까지 사용합니다.

## 실행 방법

### 1. 백엔드

```bash
cd backend
npm install
npm run seed   # 최초 1회: 샘플 창고/품목/계정 생성
npm start       # http://localhost:4000
```

### 2. 프론트엔드

```bash
cd frontend
npm install
npm run dev     # http://localhost:5173 (백엔드로 /api 프록시)
```

프로덕션 빌드 시:

```bash
npm run build
npm run preview
```

빌드 결과물(`dist/`)은 서비스워커가 포함된 PWA이며, 정적 파일 서버(Nginx 등) 뒤에 배포하고 `/api`를 백엔드로 프록시하면 됩니다. 모바일 브라우저에서 접속 후 "홈 화면에 추가"로 설치할 수 있습니다.

## 샘플 계정 (`npm run seed` 실행 시 생성)

| 아이디 | 비밀번호 | 역할 |
|---|---|---|
| admin | admin1234 | 관리자 |
| office1 | office1234 | 사무실 |
| field1 | field1234 | 현장 (서울지사 제설창고) |
| field2 | field1234 | 현장 (강원지사 제설창고) |

운영 환경에서는 반드시 비밀번호를 변경하고, `JWT_SECRET` 환경변수를 별도로 설정하세요.

## 주요 화면

- **로그인**: 아이디/비밀번호 로그인
- **대시보드** (사무실/관리자): 창고별 재고량 차트, 부족재고 알림, 최근 입출고 현황
- **입출고 등록** (전체): 창고·품목·유형(입고/출고/조정)·수량을 큰 버튼 위주로 빠르게 입력하는 현장 친화적 화면. 오프라인이어도 저장 가능
- **재고 현황** (전체): 창고별 품목 재고와 최소기준 대비 부족 여부
- **이력 조회** (전체): 창고/유형/기간 필터로 입출고 이력 검색
- **창고/품목/사용자 관리** (관리자): 마스터 데이터 및 계정 관리

## 환경 변수 (백엔드)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 4000 | API 서버 포트 |
| `DATA_DIR` | `backend/data` | SQLite 파일 저장 위치 |
| `JWT_SECRET` | `dev-secret-change-me` | JWT 서명 키 (운영 배포 시 반드시 변경) |

## 향후 확장 아이디어

- 발주 요청 → 사무실 승인 → 입고 처리로 이어지는 승인 워크플로우
- 부족재고 알림 푸시/문자 발송
- 창고별 담당자 다중 배정, 감사 로그
